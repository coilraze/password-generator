# Password Generator

A small browser-based tool that creates a 14-character password using uppercase and lowercase letters, numbers, and symbols. It uses the Web Crypto API for random values and lets you copy the generated password to the clipboard.

## Run locally

1. Download or clone this repository.
2. Open `inedx.html` in a modern browser. (The HTML file currently uses this filename.)
3. Select **Generate** to create a password, then use the copy icon to copy it.

Clipboard access may require HTTPS or localhost in some browsers. The page loads its fonts and icons from external CDNs.

## Built with

- HTML
- CSS
- JavaScript (Web Crypto API and Clipboard API)

# Генератор паролей

Небольшой генератор паролей для браузера. Создаёт пароль из 14 символов, используя заглавные и строчные латинские буквы, цифры и специальные символы. Для получения случайных значений используется Web Crypto API; готовый пароль можно скопировать в буфер обмена.

## Запуск

1. Скачайте или клонируйте этот репозиторий.
2. Откройте файл `inedx.html` в современном браузере. (Сейчас HTML-файл имеет именно такое имя.)
3. Нажмите **Generate**, чтобы создать пароль, затем нажмите значок копирования.

Некоторые браузеры разрешают доступ к буферу обмена только по HTTPS или с localhost. Шрифты и иконки загружаются со сторонних CDN.

## Использованные технологии

- HTML
- CSS
- JavaScript (Web Crypto API и Clipboard API)
